GATE DA Practice Studio

Run on any computer:
1. Extract the folder or ZIP.
2. Open index.html in a modern browser.

Keep index.html, questions.js, and the qimages folder together. The question bank and GATE 2024–2026 paper images are included. The site works without an account or API key.

To publish it as a website, deploy the contents of this folder to a static hosting service. The React/Vercel project is in the main project folder.

The GATE DA countdown updates every second and targets the first paper on 6 February 2027 (India time).
